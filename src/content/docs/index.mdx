## What This Is

A **two-part workshop** where you build real AI systems from scratch. Not a lecture. Not a demo you watch. You write code, break things, fix them, and walk away with working systems you understand inside out.

<CardGrid>
  <Card title="Part 1: Agent Development" icon="rocket">
    **Duration: 2 Days**

    Build an autonomous agent that reasons, makes decisions, calls tools, and completes tasks without human intervention.

    By the end: a working multi-step agent with MCP tool integration, conditional logic, and human-in-the-loop approval.
  </Card>
  <Card title="Part 2: RAG" icon="open-book">
    **Duration: 2 Days**

    Build a system that answers questions from your own documents — accurately, with citations, at production quality.

    By the end: a RAG pipeline with advanced retrieval, re-ranking, evaluation metrics, and a caching layer.
  </Card>

## Who This Is For

You're a developer. Maybe you've used ChatGPT. Maybe you haven't touched AI at all. Doesn't matter. Everything is explained from scratch, but we move fast and go deep.

- **New to AI?** Follow the main path. Every concept is built up from zero with real code.
- **Already familiar?** Look for the **Deep Dive** sections and tackle the **Challenge** exercises.
- **Senior/Architect?** The production patterns, security considerations, and architectural decisions are where you'll get the most value.

## How It Works

Each part takes 2 days. Here's the rhythm:

<Steps>
1. **See it work** — Every module opens with the finished result. You see what you're building before writing a single line.

2. **Understand why** — Short, focused explanation. No filler. Exactly what you need to build it yourself.

3. **Build it yourself** — Open the Colab notebook, run the code, modify it, break it, understand it. This is where learning happens.

4. **Push further** — Challenge exercises for those who want to go deeper. No hand-holding — just a goal and some hints.
</Steps>

## Before You Start

You need:
- A Google account (for Colab notebooks)
- A **free** Groq API key (see setup below)
- Basic Python knowledge (variables, functions, loops — that's it)

You don't need:
- Any AI/ML experience
- GPU access or paid API subscriptions
- Local Python installation
- Prior knowledge of LangChain, embeddings, or vector databases

### API Key Setup (2 minutes, free)

All exercises use **Groq** for LLM calls — completely free, no credit card required. Embeddings run locally in Colab with no API key needed.

<Steps>
1. Go to [console.groq.com/keys](https://console.groq.com/keys)
2. Create an account (Google or email)
3. Click **"Create API Key"**
4. Copy the key — you'll paste it into the first cell of every notebook
</Steps>

<Aside type="tip">
Groq's free tier gives you 30 requests per minute with Llama 3.3 70B — a powerful open-source model. More than enough for all exercises.
</Aside>
