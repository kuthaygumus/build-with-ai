## What This Is

A **four-day workshop** where you build real AI systems from scratch. Not a lecture. Not a demo you watch. You write code, break things, fix them, and walk away with working systems you understand inside out.

<CardGrid>
  <Card title="Session 1: LLM to Agent" icon="rocket">
    **Days 1-2**

    Start with "What is an LLM?" and build up to a production-ready agent that reasons, makes decisions, calls tools, and handles errors.

    By the end: a working LangGraph agent with MCP tool integration, conditional logic, and guardrails.
  </Card>
  <Card title="Session 2: Knowledge-Powered Agents" icon="open-book">
    **Days 3-4**

    Give your agent knowledge. Build a RAG pipeline, master advanced retrieval, and combine everything into **Agentic RAG**.

    By the end: an autonomous agent that decides when to search, evaluates sufficiency, and generates cited answers from your documents.
  </Card>
</CardGrid>

## Who This Is For

You're a developer. Maybe you've used ChatGPT. Maybe you haven't touched AI at all. Doesn't matter. Everything is explained from scratch, but we move fast and go deep.

- **New to AI?** Follow the main path. Every concept starts with "What is this?" and "Why do I need it?"
- **Already familiar?** Look for the **Deep Dive** sections and tackle the **Challenge** exercises.
- **Senior/Architect?** Production patterns, security considerations, and architectural decisions are where you'll get the most value.

## How It Works

Every module follows the same rhythm:

<Steps>
1. **Feel the problem** — See what doesn't work. Experience the limitation firsthand.

2. **Understand why** — Short, focused explanation. Why this technology exists. What problem it solves.

3. **Build the solution** — Open the Colab notebook, write the code, see it work.

4. **Push further** — Challenge exercises for those who want to go deeper.
</Steps>

## Before You Start

You need:
- A Google account (for Colab notebooks)
- A **free** Groq API key (see setup below)
- Basic Python knowledge (variables, functions, loops — that's it)

You don't need:
- Any AI/ML experience
- GPU access or paid API subscriptions
- Local Python installation
- Prior knowledge of LangChain, embeddings, or vector databases

### API Key Setup (2 minutes, free)

All exercises use **Groq** for LLM calls — completely free, no credit card required. Embeddings run locally in Colab with no API key needed.

<Steps>
1. Go to [console.groq.com/keys](https://console.groq.com/keys)
2. Create an account (Google or email)
3. Click **"Create API Key"**
4. Copy the key — you'll paste it into the first cell of every notebook
</Steps>

<Aside type="tip">
Groq's free tier gives you 30 requests per minute with Llama 3.3 70B — a powerful open-source model. More than enough for all exercises.
</Aside>
