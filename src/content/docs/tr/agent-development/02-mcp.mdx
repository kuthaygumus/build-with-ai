## Mimari: Üç Katman

MCP tek bir bağlantı değil. Net sorumluluk ayrımına sahip katmanlı bir sistem — ve bu ayrım güvenlik için önemli.

<Steps>
1. **Host** — Kullanıcının etkileşimde olduğu uygulama. Güvenliği, kullanıcı onayını yönetir ve istemcileri başlatır. Claude Desktop, Cursor veya kendi agent uygulamanızı düşünün.

2. **Client** — Host'un içinde yaşar. Her istemci tek bir MCP sunucusuna 1:1 bağlantı sürdürür. Bir sunucu çökerse, diğerleri çalışmaya devam eder. Tasarım gereği izolasyon.

3. **Server** — Protokol üzerinden yetenekleri (araçlar, kaynaklar, prompt'lar) sunar. Harici bir sistemi — veritabanı, API, dosya sistemi — sarar ve AI'a standart bir şekilde erişilebilir kılar.
</Steps>

Neden iki yerine üç katman? **Güvenlik.** Host, AI'ın neye erişebileceğini kontrol eder. Client izolasyon sağlar — kötü davranan bir sunucu diğerlerini zehirleyemez. Server sandbox'lanmıştır, yalnızca sunmak üzere tasarlandığı şeyleri sunar.

</PresenterNote>

## Transport: Mesajlar Nasıl Taşınır

MCP transport-agnostiktir — mesajlar nasıl iletilirse iletilsin JSON-RPC 2.0 kullanır. İki ana seçenek:

<Tabs>
  <TabItem label="stdio (Yerel)">
    Sunucu, host'un bir **alt süreci** olarak çalışır. İletişim stdin/stdout üzerinden. Host onu başlatır, onunla konuşur, işi bitince sonlandırır.

    ```json
    {
      "mcpServers": {
        "flight-data": {
          "command": "python",
          "args": ["flight_mcp_server.py"],
          "env": {
            "API_KEY": "your-key-here"
          }
        }
      }
    }
    ```

    **En uygun**: Yerel geliştirme, CLI araçları, kişisel otomasyon. Sıfır ağ yükü.
  </TabItem>

  <TabItem label="Streamable HTTP (Uzak)">
    Sunucu bir **web servisi** olarak çalışır. İstekler için HTTP, isteğe bağlı streaming için SSE. Yük dengeleyiciler, proxy'ler, standart kimlik doğrulama ile çalışır.

    ```json
    {
      "mcpServers": {
        "flight-data": {
          "url": "https://mcp.internal.example.com/flights",
          "headers": {
            "Authorization": "Bearer ${FLIGHT_API_TOKEN}"
          }
        }
      }
    }
    ```

    **En uygun**: Üretim dağıtımları, paylaşılan altyapı, ekip çapında araçlar. Bu, eski HTTP+SSE yaklaşımının yerini alan daha yeni transport'tur (2025).
  </TabItem>
</Tabs>

<Aside type="note">
Streamable HTTP, üretim için önerilen transport'tur. Yeniden bağlantıyı yönetir, hem istek-yanıt hem de streaming'i destekler ve mevcut HTTP altyapısıyla entegre olur.
</Aside>

### Araçlar (Tools) — Model Kontrollü

Araçlar, AI'ın çağırmaya karar verdiği fonksiyonlardır. En yaygın yapı taşıdır ve zamanınızın %90'ında kullanacağınız şeydir.

```python
from mcp.server import Server

server = Server("travel-flights")

@server.tool()
async def search_flights(
    origin: str,
    destination: str,
    date: str,
    passengers: int = 1
) -> str:
    """Search available flights between two airports on a given date.
    
    Args:
        origin: IATA airport code (e.g., 'CDG')
        destination: IATA airport code (e.g., 'NRT')
        date: Travel date in YYYY-MM-DD format
        passengers: Number of passengers (default: 1)
    
    Returns:
        Available flights with prices and schedules
    """
    results = await flight_api.search(origin, destination, date, passengers)
    return format_flight_results(results)
```

AI modeli araç adını, açıklamasını ve parametre şemasını görür — sonra ne zaman ve nasıl çağıracağına karar verir. Docstring kritiktir: aracınız için AI'ın kullanım kılavuzudur.

### Kaynaklar (Resources) — Uygulama Kontrollü

Kaynaklar, AI'ın erişebildiği salt okunur verilerdir. GET endpoint'leri gibi düşünün — host'un dahil etmeye karar verdiği bağlam.

```python
@server.resource("flights://status/{flight_number}")
async def get_flight_status(flight_number: str) -> str:
    """Get real-time status of a specific flight."""
    status = await flight_api.get_status(flight_number)
    return json.dumps(status, indent=2)
```

Kaynaklar URI şablonları kullanır. AI nelerin mevcut olduğuna göz atar ve harekete geçmeden önce ihtiyaç duyduğunu okur.

### Prompt'lar — Kullanıcı Kontrollü

Prompt'lar, sunucunun sağladığı yeniden kullanılabilir şablonlardır. Kullanıcı bunları bir menüden seçer — AI'ın alan-spesifik görevlere nasıl yaklaşacağını standartlaştırır.

```python
@server.prompt()
async def disruption_analysis(flight_number: str) -> str:
    """Analyze a flight disruption and suggest rebooking options."""
    return f"""Analyze the disruption for flight {flight_number}.

Steps:
1. Check current flight status
2. Identify affected passengers
3. Search for alternative flights
4. Rank alternatives by: passenger tier, connection feasibility, cost
5. Generate a rebooking recommendation report"""
```

<KeyInsight>
**Araçlar** = model kontrollü (AI çağırmaya karar verir). **Kaynaklar** = uygulama kontrollü (host dahil etmeye karar verir). **Prompt'lar** = kullanıcı kontrollü (kullanıcı seçer). Üç yapı taşı, üç kontrol düzlemi.
</KeyInsight>

## Uygulamalı: MCP Sunucusu Geliştirme

Sıfırdan bir uçuş bilgi sunucusu geliştirelim. Bu, Flight API'lerini herhangi bir AI istemcisine sunmak için geliştireceğiniz türde bir sunucu.

<ColabLink title="Alıştırma: İlk MCP Sunucunuzu Geliştirin" notebook="/notebooks/agent-dev/01-mcp-server.ipynb" level="Basic" />

```python
# flight_mcp_server.py
import json
from mcp.server import Server
from mcp.server.stdio import stdio_server

server = Server("travel-flight-tools")

# Simulated flight data (in production, this calls a real API)
FLIGHTS_DB = {
    "AF1234": {
        "carrier": "Air France", "origin": "CDG", "destination": "NRT",
        "departure": "2026-09-15T10:30:00", "arrival": "2026-09-16T05:45:00",
        "status": "on_time", "aircraft": "A350-900", "passengers": 287
    },
    "AF5678": {
        "carrier": "Air France", "origin": "CDG", "destination": "JFK",
        "departure": "2026-09-15T14:00:00", "arrival": "2026-09-15T16:30:00",
        "status": "delayed", "delay_minutes": 45,
        "aircraft": "B777-300ER", "passengers": 342
    }
}

@server.tool()
async def get_flight_status(flight_number: str) -> str:
    """Get the current status of a flight by its flight number.

    Args:
        flight_number: The flight number (e.g., 'AF1234')

    Returns:
        Flight status including departure, arrival, and delay info
    """
    flight = FLIGHTS_DB.get(flight_number.upper())
    if not flight:
        return f"Flight {flight_number} not found."

    status_info = {
        "flight": flight_number.upper(),
        "carrier": flight["carrier"],
        "route": f"{flight['origin']} → {flight['destination']}",
        "status": flight["status"],
        "departure": flight["departure"],
        "arrival": flight["arrival"],
    }
    if flight.get("delay_minutes"):
        status_info["delay_minutes"] = flight["delay_minutes"]

    return json.dumps(status_info, indent=2)

@server.tool()
async def list_flights(origin: str = "", destination: str = "") -> str:
    """List available flights, optionally filtered by origin/destination.

    Args:
        origin: Filter by origin airport IATA code (optional)
        destination: Filter by destination airport IATA code (optional)
    """
    results = []
    for fn, data in FLIGHTS_DB.items():
        if origin and data["origin"] != origin.upper():
            continue
        if destination and data["destination"] != destination.upper():
            continue
        results.append({
            "flight_number": fn,
            "route": f"{data['origin']} → {data['destination']}",
            "departure": data["departure"],
            "status": data["status"]
        })

    if not results:
        return "No flights found matching the criteria."
    return json.dumps(results, indent=2)

async def main():
    async with stdio_server() as (read_stream, write_stream):
        await server.run(read_stream, write_stream)

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())
```

### Güvenlik Değerlendirmeleri

MCP yeni bir saldırı yüzeyi oluşturur. Üç savunma katmanı:

**1. Araç Onayı** — Host, yürütmeden önce kullanıcıya hangi aracın hangi argümanlarla çağrıldığını gösterir:

```
AI wants to call: delete_booking(booking_id="ABC123")
[Allow] [Deny] [Allow All for this session]
```

**2. Kapsamlı İzinler** — Sunucular en az yetki erişimi uygular. Salt okunur bir sunucu asla yazamaz:

```python
@server.tool()
async def search_flights(origin: str, destination: str) -> str:
    """Read-only search — no modifications allowed."""
    pass
```

**3. Girdi Doğrulama** — Araç girdilerine körü körüne güvenmeyin. Bunlar LLM'den gelir ve LLM prompt injection ile manipüle edilebilir:

```python
@server.tool()
async def query_database(sql_query: str) -> str:
    """Execute a read-only SQL query."""
    if not sql_query.strip().upper().startswith("SELECT"):
        return "Error: Only SELECT queries are allowed."
    
    async with read_only_pool.acquire() as conn:
        result = await conn.fetch(sql_query)
    return json.dumps(result)
```

### Uzak Sunucular İçin OAuth 2.1

Üretim Streamable HTTP sunucuları, OAuth 2.1 aracılığıyla mevcut kimlik sağlayıcılarla (Active Directory, Okta) entegre olur. İstemci, yetkilendirme sunucusundan bir erişim token'ı alır, ardından MCP isteklerinde Bearer token olarak ekler. Bu, kurumsal güvenlik politikalarının protokol düzeyinde uygulanmasını sağlar.

</DeepDive>
