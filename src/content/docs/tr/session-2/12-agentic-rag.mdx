## Agent'ların RAG'a İhtiyacı (ve Tam Tersi)

| | Yalnız Agent | Yalnız RAG | Agentic RAG |
|---|---|---|---|
| **Aksiyon alabilir** | Evet | Hayır | Evet |
| **Bilgi sahibi** | Hayır (halüsinasyon) | Evet (dokümanlardan) | Evet |
| **Neyi arayacağına karar verir** | — | Hayır (kullanıcı sorguları) | Evet (otonom) |
| **Yeterliliği değerlendirir** | — | Hayır | Evet |
| **Farklı sorgularla tekrar dener** | — | Hayır | Evet |
| **Birden fazla kaynağı birleştirir** | — | Manuel | Otonom |

<KeyInsight>
RAG reaktiftir — soru gelir, yanıt döner. Agentic RAG proaktiftir — agent ne zaman arama yapacağına karar verir, bağlamın yeterli olup olmadığını değerlendirir ve yeterli olmadığında sorguları yeniden formüle eder. Agent **otonomi** getirir. RAG **bilgi** getirir. Birlikte: otonom bilgi.
</KeyInsight>

### Karar 1: Arama Yapmalı mıyım?

Her sorunun arama gerektirmesi gerekmez. "2+2 kaç eder?" için doküman araması gerekmez. "İptal politikamız nedir?" için gerekir.

```python
def route_question(state: AgenticRAGState) -> str:
    """Decide if retrieval is needed."""
    response = model.invoke([
        SystemMessage(content="""Classify the question:
- "retrieve" if it asks about specific policies, procedures, or company data
- "direct" if it's general knowledge or simple reasoning"""),
        HumanMessage(content=state["question"])
    ])
    return "retrieve" if "retrieve" in response.content.lower() else "direct"
```

### Karar 2: Bağlam Yeterli mi?

Arama sonrasında agent değerlendirir: güvenle yanıt vermek için yeterli bilgiye sahip miyim?

```python
def evaluate_context(state: AgenticRAGState) -> str:
    """Judge if retrieved context is sufficient."""
    response = model.invoke([
        SystemMessage(content="""Given the question and context, can you answer confidently?
Reply ONLY "sufficient" or "insufficient".
Insufficient means: key information is missing, context is off-topic, or contradictory."""),
        HumanMessage(content=f"Question: {state['question']}\n\nContext: {state['context']}")
    ])
    return "generate" if "sufficient" in response.content.lower() else "reformulate"
```

### Karar 3: Yeniden Formüle Etmeli miyim?

Bağlam yetersizse, agent farklı bir arama stratejisi dener — farklı anahtar kelimeler, daha geniş kapsam veya farklı bir açı.

```python
def reformulate_query(state: AgenticRAGState) -> dict:
    """Generate a better search query based on what was missing."""
    response = model.invoke([
        SystemMessage(content="The previous search didn't find enough information. Reformulate the query to find the missing pieces. Return ONLY the new search query."),
        HumanMessage(content=f"Original: {state['question']}\nPrevious context (insufficient): {state['context'][:500]}")
    ])
    return {
        "search_query": response.content,
        "retrieval_attempts": state.get("retrieval_attempts", 0) + 1
    }
```

## İnşa Edelim: LangGraph + RAG

Bu, Modül 5'teki **aynı conditional routing pattern'ı**, arama işlemine uygulanmış hali:

```python
from typing import Annotated
from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_groq import ChatGroq
from langchain_core.messages import SystemMessage, HumanMessage

class AgenticRAGState(TypedDict):
    question: str
    search_query: str
    context: str
    answer: str
    sources: list[str]
    retrieval_attempts: int

model = ChatGroq(model="llama-3.3-70b-versatile", temperature=0)

def retrieve(state: AgenticRAGState) -> dict:
    """Search the vector store for relevant documents."""
    query = state.get("search_query", state["question"])
    docs = vectorstore.similarity_search(query, k=4)
    context = "\n\n".join([
        f"[Source: {doc.metadata.get('source', 'unknown')}]\n{doc.page_content}"
        for doc in docs
    ])
    sources = [doc.metadata.get("source", "unknown") for doc in docs]
    return {"context": context, "sources": sources}

def generate(state: AgenticRAGState) -> dict:
    """Generate a grounded, cited answer."""
    response = model.invoke([
        SystemMessage(content="""Answer the question based ONLY on the provided context.
Include citations: reference the source document for each claim.
If the context doesn't contain the answer, say so explicitly."""),
        HumanMessage(content=f"Question: {state['question']}\n\nContext:\n{state['context']}")
    ])
    return {"answer": response.content}

def direct_answer(state: AgenticRAGState) -> dict:
    """Answer without retrieval for general questions."""
    response = model.invoke([
        SystemMessage(content="Answer this general knowledge question concisely."),
        HumanMessage(content=state["question"])
    ])
    return {"answer": response.content, "sources": []}

def should_stop_reformulating(state: AgenticRAGState) -> str:
    """Stop after 3 retrieval attempts."""
    if state.get("retrieval_attempts", 0) >= 3:
        return "generate"  # Best effort with what we have
    return "reformulate"
```

### Graph'ı Bağlama

```python
builder = StateGraph(AgenticRAGState)

# Node'ları ekle
builder.add_node("retrieve", retrieve)
builder.add_node("evaluate", evaluate_context_node)
builder.add_node("reformulate", reformulate_query)
builder.add_node("generate", generate)
builder.add_node("direct_answer", direct_answer)

# Giriş: arama gerekli mi karar ver
builder.add_conditional_edges(
    START,
    route_question,
    {"retrieve": "retrieve", "direct": "direct_answer"}
)

# Arama sonrası: yeterliliği değerlendir
builder.add_edge("retrieve", "evaluate")

# Değerlendirme sonrası: üret veya tekrar dene
builder.add_conditional_edges(
    "evaluate",
    evaluate_context,
    {"generate": "generate", "reformulate": "reformulate"}
)

# Yeniden formülasyon sonrası: deneme sayısını kontrol et
builder.add_conditional_edges(
    "reformulate",
    should_stop_reformulating,
    {"reformulate": "retrieve", "generate": "generate"}  # Döngüye dön veya vazgeç
)

# Terminal node'lar
builder.add_edge("generate", END)
builder.add_edge("direct_answer", END)

graph = builder.compile()
```

### Corrective RAG (CRAG)

Vector store araması başarısız olduğunda, web aramasına düş:

```python
def route_after_evaluation(state):
    if state["context_quality"] == "sufficient":
        return "generate"
    elif state["retrieval_attempts"] < 2:
        return "reformulate"
    else:
        return "web_search"  # Web aramasına düş

def web_search(state):
    """Fall back to web search when vector store fails."""
    results = web_search_tool.search(state["question"])
    return {"context": results, "sources": ["web"]}
```

### Maliyet Bilinçli Model Yönlendirme

Yönlendirme için ucuz modeller, üretim için güçlü modeller kullanın:

```python
haiku = ChatGroq(model="llama-3.1-8b-instant", temperature=0)  # Hızlı, ucuz
sonnet = ChatGroq(model="llama-3.3-70b-versatile", temperature=0)  # Güçlü

def route_question(state):
    # Ucuz model arama gerekip gerekmediğine karar verir
    return haiku.invoke(routing_prompt)

def generate(state):
    # Güçlü model yanıtı üretir
    return sonnet.invoke(generation_prompt)
```

### Çoklu Kaynak RAG

Soru türüne göre farklı bilgi tabanlarına yönlendirin:

```python
def route_to_knowledge_base(state):

    if category == "policy":
        return "policy_vectorstore"
    elif category == "technical":
        return "api_docs_vectorstore"
```
